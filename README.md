
# To-Do List CLI Application

## Project Overview
A simple command-line To-Do List application developed using Python. It allows users to add, view, and remove tasks while storing tasks permanently using file handling.

## Features
- Add new tasks
- View all saved tasks
- Remove tasks
- Input validation
- Permanent task storage
- Automatically loads previously saved tasks

## Technologies Used
- Python
- File Handling
- Lists
- Functions
- Exception Handling

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python todo.py
```
